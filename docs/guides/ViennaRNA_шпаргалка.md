# ViennaRNA: пошаговая шпаргалка

Для того, чтобы самому воспроизвести расчёты по PegRNA3 и уметь
ответить на вопросы научного руководителя «а покажи, как ты это
посчитал».

Всё делается в Python. Отдельная программа RNAfold из командной строки
тоже существует, но питоновский модуль удобнее: он умеет то, что через
командную строку сделать нельзя, — например считать барьер укладки.

## 1. Самое базовое: свернуть РНК

Создайте файл `проба.py` в папке репозитория и вставьте:

```python
import RNA

seq = "GGGAAACUCCCUUUCGGGAGUUUCCC"

structure, energy = RNA.fold(seq)

print(seq)
print(structure)
print(f"MFE = {energy:.2f} kcal/mol")
```

Запустите: `python3 проба.py`

Что вы увидите: строку из скобок и точек. Это **dot-bracket notation** —
стандартная запись вторичной структуры:

- `.` — нуклеотид ни с чем не спарен,
- `(` и `)` — парные скобки обозначают спаренные нуклеотиды.

`(` в позиции 3 и `)` в позиции 20 означают, что нуклеотид 3 спарен
с нуклеотидом 20. Скобки всегда вложены как в математике.

**MFE** = minimum free energy, минимальная свободная энергия. Чем
отрицательнее, тем стабильнее структура. Это самая вероятная одиночная
структура, но не единственная, которую молекула принимает.

## 2. Правильный способ: fold_compound

`RNA.fold()` — быстрый вариант для одной строчки. Для всего серьёзного
используется объект `fold_compound`, потому что только он умеет
принимать ограничения и считать ансамбль.

```python
import RNA

seq = "GGGAAACUCCCUUUCGGGAGUUUCCC"

# Модель: температура, параметры. Всегда задавайте явно.
md = RNA.md()
md.temperature = 37.0          # градусы Цельсия

fc = RNA.fold_compound(seq, md)

structure, energy = fc.mfe()
print(structure, energy)
```

Почему температуру нужно задавать явно: 37 °C — это условия в клетке
млекопитающего. По умолчанию ViennaRNA и так берёт 37, но если вы
работаете с рыбками данио, там 28 °C, и результат будет другой. Явная
запись избавляет от вопроса «а при какой температуре это считали».

---

## 3. Ансамбль: насколько структура на самом деле надёжна

MFE — это одна структура. В реальности молекула постоянно переключается
между многими. Чтобы узнать, с какой вероятностью конкретные нуклеотиды
спарены, считают **partition function** (статсумму).

```python
import RNA

seq = "GGGAAACUCCCUUUCGGGAGUUUCCC"
md = RNA.md(); md.temperature = 37.0
fc = RNA.fold_compound(seq, md)

# Сначала MFE — её значение нужно для численной стабилизации
structure, mfe_energy = fc.mfe()
fc.exp_params_rescale(mfe_energy)   # без этой строки длинные РНК ломаются

ensemble_structure, ensemble_energy = fc.pf()

print(f"MFE                 = {mfe_energy:.2f}")
print(f"энергия ансамбля    = {ensemble_energy:.2f}")
print(f"центроид ансамбля: {ensemble_structure}")
```

Энергия ансамбля всегда чуть отрицательнее MFE. Если разница большая —
у молекулы много конкурирующих структур, то есть она «неопределившаяся».

### Вероятности спаривания

```python
bpp = fc.bpp()      # матрица; ОБЯЗАТЕЛЬНО после fc.pf()

# bpp[i][j] = вероятность, что нуклеотид i спарен с j. Нумерация с 1!
print(bpp[3][24])   # для примера выше выведет 1.000
```

Важная деталь, на которой легко ошибиться: **нумерация с единицы**,
а не с нуля, как обычно в Python. И всегда `bpp[меньший][больший]`.

### Доступность: вероятность быть НЕспаренным

Это ключевая величина для guide RNA — спейсер должен быть свободен,
чтобы спариться с ДНК.

```python
n = len(seq)

def accessibility(position):
    """Вероятность, что нуклеотид не спарен ни с чем."""
    paired = sum(
        bpp[min(position, other)][max(position, other)]
        for other in range(1, n + 1)
        if other != position
    )
    return 1.0 - paired

for p in range(1, 11):
    print(f"{p:3d} {seq[p-1]}  доступность {accessibility(p):.3f}")
```

Логика простая: суммируем вероятности всех пар, в которых участвует
нуклеотид, и вычитаем из единицы.

## 4. Ограничения: заставить нуклеотид быть свободным или спаренным

Это то, чем моделируются линкеры и модифицированные нуклеотиды.

### Запретить спаривание (моделирует абазический сайт, UNA, триазол)

```python
fc = RNA.fold_compound(seq, md)

# Нуклеотид 5 не может быть ни с чем спарен
fc.hc_add_up(5, RNA.CONSTRAINT_CONTEXT_ALL_LOOPS)

structure, energy = fc.mfe()
```

`hc` = hard constraint, жёсткое ограничение. `up` = unpaired.
`ALL_LOOPS` означает «во всех структурных контекстах», то есть запрет
абсолютный.

### Принудительно создать пару (моделирует известную структуру из крио-ЭМ)

```python
fc.hc_add_bp(10, 25,
             RNA.CONSTRAINT_CONTEXT_ALL_LOOPS
             | RNA.CONSTRAINT_CONTEXT_ENFORCE)
```

Без флага `ENFORCE` вы говорите «пара разрешена», с ним — «пара
обязана быть».

Ограничения **накапливаются**: вызвали `hc_add_up` пять раз — все пять
позиций заблокированы. Чтобы начать заново, создайте новый
`fold_compound`. Это частая ошибка: переиспользовать объект и получить
непонятный результат.

## 5. Folding Barrier: главный расчёт

Идея: у РНК есть основное состояние (то, во что она сворачивается сама)
и активное состояние (то, что нужно белку). Важно не насколько
стабильно основное состояние, а насколько трудно из него выбраться.

```python
import RNA

seq = "..."   # ваша последовательность
md = RNA.md(); md.temperature = 37.0

# Состояние 1: свободная РНК сама по себе
fc = RNA.fold_compound(seq, md)
ground_structure, ground_energy = fc.mfe()

# Состояние 2: активная структура. Как её построить — см. раздел 6.
active_structure = "....((((....))))...."   # пример

# Путь между ними
fc_path = RNA.fold_compound(seq, md)
saddle = fc_path.path_findpath_saddle(ground_structure,
                                      active_structure,
                                      400)     # ширина поиска

saddle_kcal = saddle / 100.0        # ВАЖНО: функция возвращает 0.01 ккал/моль
barrier = saddle_kcal - ground_energy

print(f"основное состояние : {ground_energy:.2f}")
print(f"седловая точка     : {saddle_kcal:.2f}")
print(f"Folding Barrier    : {barrier:.2f} kcal/mol")
```

Две вещи, о которых нужно помнить и которые стоит сказать вслух, если
спросят:

1. **Деление на 100.** `path_findpath_saddle` возвращает энергию в
   сотых долях ккал/моль (целое число). Забудете поделить — получите
   число в 100 раз больше.
2. **Это верхняя оценка.** Findpath — эвристика: она перебирает
   ограниченное число путей перестройки, а не все. Настоящий барьер
   может быть только ниже. Параметр `400` — сколько путей смотреть;
   больше = точнее и медленнее.

Чтобы увидеть сам путь по шагам, а не только его вершину:

```python
path = fc_path.path_findpath(ground_structure, active_structure, 400)
for step in path:
    print(f"{step.en:7.2f}  {step.s}")     # здесь БЕЗ деления на 100
```

**Осторожно, это настоящая ловушка в API.** Две родственные функции
возвращают энергию в разных единицах:

| Функция | Единицы | Что делать |
|---|---|---|
| `path_findpath_saddle()` | сотые доли ккал/моль, целое число | делить на 100 |
| `path_findpath()`, поле `step.en` | ккал/моль, уже готовое число | НЕ делить |

Проверяется в одну строчку: `path_findpath_saddle` для нашего примера
возвращает `950`, а максимальное `step.en` на том же пути — `9.5`.
Если ваш барьер получился в районе тысяч, вы поделили не там.

## 6. Как построить «активную структуру»

Это не расчёт, а решение исследователя, и его надо уметь защитить.

В нашем случае активная структура берётся из крио-ЭМ структуры
праймредактора: какие пары реально видны в комплексе с белком.

```python
# Пары, наблюдаемые в структуре, в нашей нумерации
pairs = [(22, 51), (23, 50), (24, 49)]   # и так далее

fc = RNA.fold_compound(seq, md)

# 1. Заставляем эти пары существовать
for i, j in pairs:
    fc.hc_add_bp(i, j,
                 RNA.CONSTRAINT_CONTEXT_ALL_LOOPS
                 | RNA.CONSTRAINT_CONTEXT_ENFORCE)

# 2. Спейсер держим свободным: Cas9 растягивает его для чтения ДНК
for position in range(1, 22):
    fc.hc_add_up(position, RNA.CONSTRAINT_CONTEXT_ALL_LOOPS)

# 3. Всё остальное пусть сворачивается как хочет
active_structure, _ = fc.mfe()
```

Две ловушки, в которые я попал при первом расчёте:

- **Не все пары из структуры можно использовать.** Модель ближайших
  соседей запрещает шпилечные петли короче 3 нуклеотидов и не имеет
  параметров для неканонических пар. В нашем случае из 24 пар
  пришлось выбросить две. Это не провал метода: белок удерживает
  геометрию, которую свободная РНК принять не может. Но выброшенные
  пары надо называть вслух, а не молча пропускать.
- **Энергию активной структуры надо считать в свободной модели.**
  Если посчитать её тем же `fold_compound` с ограничениями, вы
  получите энергию модели с ограничениями, а не реальную энергию
  структуры. Правильно:

  ```python
  free = RNA.fold_compound(seq, md)     # БЕЗ ограничений
  active_energy = free.eval_structure(active_structure)
  ```

## 7. Внутримолекулярный дуплекс: спейсер против PBS

Отдельный инструмент для вопроса «насколько сильно два фрагмента
слипаются друг с другом».

```python
import RNA

spacer = "ACAGGGUGUGGCAGAAGCAGC"
pbs    = "GCUUCUGCCACA"

duplex = RNA.duplexfold(spacer, pbs)

print(f"dG        = {duplex.energy:.2f} kcal/mol")
print(f"структура = {duplex.structure}")
print(f"начало в spacer = {duplex.i}, начало в pbs = {duplex.j}")
```

`duplexfold` считает только межмолекулярные пары, игнорируя
внутреннюю структуру каждого фрагмента. Для быстрой оценки «эти два
куска комплементарны и насколько сильно» — идеально.

## 9. Частые ошибки

| Ошибка | Что происходит | Как чинить |
|---|---|---|
| `bpp()` до `pf()` | пустая матрица или мусор | сначала `fc.pf()`, потом `fc.bpp()` |
| нумерация с 0 | сдвиг на один нуклеотид везде | в ViennaRNA нумерация с 1 |
| забыли `/100` в findpath | барьер в 100 раз больше | `saddle / 100.0` |
| переиспользовали `fold_compound` | ограничения накопились | создавайте новый объект на каждый вариант |
| нет `exp_params_rescale` | на длинных РНК переполнение | вызывать между `mfe()` и `pf()` |
| `eval_structure` на объекте с ограничениями | энергия не та | считать на чистом `fold_compound` |
